# App overview (context)

Garden Planting is a static PWA for a ~20×20 m UK garden survey. Session modes and coach copy live in `AGENTS.md`. This Petri-net pass drives **Add point** only; other activities (establish baseline, leapfrog, adjust, …) stay on the existing mode machine until migrated.

Add point (user label **+ Point**) observes a named item on a layer using the active baseline, tape, and photo marks. The Petri workflow adds: survey-layer rules (baseline / railway / flower bed / tree), fix options, plan side choice, measurement capture, and strength colouring before commit.
